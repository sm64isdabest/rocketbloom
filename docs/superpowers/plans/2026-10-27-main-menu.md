# RocketBloom Main Menu Implementation Plan

> **For agentic workers:** Implement this plan task by task inline. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Recreate the provided RocketBloom main-menu reference with its supplied artwork while preserving existing navigation.

**Architecture:** Keep the screen in `MenuScreen.jsx` and use the existing `onPlay`, `onContinue`, `onSettings`, and `onCommandRoom` callbacks. Store the provided files under `public/assets/menu/`, resolve them through the Vite base path, and use CSS for the responsive portrait composition.

**Tech Stack:** React, Vite, CSS, Node built-in test runner.

**Spec:** `docs/superpowers/specs/2026-10-27-main-menu.md`

## Global Constraints

- Preserve existing game mechanics and progress state.
- Use the attached artwork instead of recreating it.
- Do not invent a store, pricing, or purchase behavior.
- Keep every visible control accessible and connected to an action.
- Support the existing `/rocketbloom/` base path.

## Review Focus

- Missing menu image files — test the asset URL builder and verify the built assets.
- A saved game hides or breaks `Continuar` — preserve its conditional callback.
- Shop appears to sell items — verify the notice states that shopping is unavailable.
- Small viewports crop actions — check the menu at portrait and wider sizes.
- A visual control has no action — activate each visible menu control in the browser.
